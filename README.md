# حقيبة المهام | Haqibat Al-Maham

تطبيق ويب عربي لتنظيم المهام والوثائق والتراخيص والمواعيد والمشاريع في مساحة عمل مشتركة، مع تقارير ونموذج مساعد لضريبة القيمة المضافة ومساعد ذكي. يتيح الوصول إلى السجلات من أجهزة متعددة وفق صلاحيات الحساب.

**[فتح الموقع الرسمي](https://haqibat-almaham.carpetbazar.org/)**

## الوظائف

| القسم | الوظائف |
| --- | --- |
| اليوم والمهام | إنشاء المهام وتعديلها ومتابعة الأولوية والحالة والاستحقاق، وإسنادها إلى المختصين، وتنظيم أنواعها وإضافة ملصقات وملاحظات. |
| المخطط الأسبوعي | توزيع المهام على أيام الأسبوع بالسحب أو اختيار اليوم، وصندوق للمهام غير المخططة، مع فصل يوم العمل المخطط عن موعد الاستحقاق. |
| المشاريع والأفكار | إضافة المشاريع ومراحلها وربطها بالمهام والوثائق والمختص، وإدارة الأفكار وتصنيفها وتثبيتها وتحويلها إلى مهام أو مشاريع مرتبطة. |
| الإنجاز الأسبوعي | عرض إنجاز المهام المخططة خلال ثمانية أسابيع مع البحث والفلاتر، وتنزيل التقرير ومشاركة ملخصه حسب الصلاحية. |
| الوثائق والتراخيص | إدارة الوثائق وتصنيفاتها وتواريخ انتهائها وسجل التجديدات، وربطها بالمهام والمختصين. |
| القضايا والوكالات | تسجيل القضايا والجلسات والوكالات والتفويضات ومتابعة مواعيدها وسجلاتها. |
| التقويم والتنبيهات | عرض المواعيد والأحداث والتذكيرات ومتابعة السجلات القريبة من الاستحقاق. |
| المختصون والمشاركة | حفظ بيانات المختصين وتجهيز رسالة ورابط السجل لمراجعتهما ومشاركتهما عبر واتساب أو البريد الإلكتروني. |
| التقارير والإحصاءات | عرض السجلات المصفاة والرسوم، مع تنزيل التقارير ومشاركتها بحسب صلاحية الحساب. |
| ضريبة القيمة المضافة 3A | إعداد مسودات النموذج وحسابها وأرشفتها، وتخصيص النسب وقواعد التعديل والأثر الضريبي للبنود المتاحة. النموذج أداة مساعدة للمراجعة ولا يقدّم الإقرار الرسمي. |
| الحسابات والنسخ الاحتياطية | إدارة الحسابات والأدوار وإعادة تعيين كلمات المرور وتصدير النسخ التشغيلية واستعادتها وفق الصلاحيات. |

## المساعد الذكي

يتفاعل المستخدم مع المساعد كتابةً، ويمكن استخدام الإملاء الصوتي وقراءة الرد إذا دعم المتصفح والجهاز ذلك. يستخدم الخادم **Gemini** لفهم الطلب، ثم يتعامل مع وظائف التطبيق والبيانات التي تسمح بها صلاحيات المستخدم. يستطيع المساعد البحث، وطلب المعلومات الناقصة، وتجهيز نماذج لسجلات وتقارير ومشاركات للمراجعة.

### استيراد الوثائق من مرفق مؤقت

يمكن إرفاق ملف **Excel بصيغة XLSX** أو **Word بصيغة DOCX** أو **PDF** في المحادثة لاستخراج بيانات الوثائق، مثل رخص السير وتأمين المركبات. يدعم الاستيراد ملفات تصل إلى 3 ميغابايت وحتى 100 سجل في الدفعة، ويتطلب صلاحية كتابة السجلات.

تُراجع البيانات المستخرجة ويُحدد التصنيف والمختص، ثم يختار المستخدم إنشاء السجلات أو تحديث المطابق منها واعتماد الدفعة. يعالج التطبيق الملف في الذاكرة، ويرسل ملف PDF أو النص المستخرج من Excel وWord إلى Gemini. يُزال المرفق عند إغلاق المحادثة أو إزالته أو بعد 15 دقيقة؛ وتُحفظ السجلات المعتمدة فقط.

## الواجهة

واجهة عربية باتجاه من اليمين إلى اليسار، مع وضعين نهاري وداكن، وقوائم قابلة للطي. تتضمن شاشة الدخول مصباحًا بألوان إضاءة قابلة للاختيار، وبطاقة زجاجية وزرًا متحركًا.

## البنية التقنية والتخزين

- **الواجهة:** React وTypeScript وVite.
- **الخادم:** Node.js وExpress.
- **قاعدة البيانات المشتركة:** MySQL.
- **المساعد:** Gemini من خلال الخادم، بعد إعداد مفتاحه على الاستضافة.

تُحفظ بيانات مساحة العمل المشتركة في `haqibat_workspace` ضمن بنية JSON، وتُحفظ الحسابات في جدول مستقل. يستخدم الخادم رقم مراجعة لحماية التعديلات من التعارض؛ لرؤية أحدث تغييرات الأجهزة الأخرى، حدّث السجلات أو أعد فتح الصفحة. تُحفظ تفضيلات المظهر والتنقل والفلاتر في المتصفح، بينما تُحفظ إعدادات التنبيهات وقواعد الضريبة والتكاملات ضمن مساحة العمل المشتركة.

تستثني النسخة التشغيلية المصدّرة حسابات الدخول والمرفقات الثنائية، وتحتفظ قاعدة البيانات بحالة سابقة عند الاستعادة. راجع دليل الاستضافة لمعرفة كيفية حماية الحسابات وقاعدة البيانات.

## التشغيل المحلي

يتطلب المشروع **Node.js 22.12 أو أحدث**:

```sh
npm ci
npm run dev
```

يعمل التشغيل الافتراضي في وضع المعاينة المحلية، وهو مستقل عن قاعدة البيانات المشتركة. للفحص وبناء النسخة المشتركة:

```sh
npm run lint
npm run build:shared
node --import tsx --test tests/*.test.ts
```

## إعداد الاستضافة

راجع [دليل إعداد هوستينجر وMySQL](database/HOSTINGER.md) لإعداد قاعدة البيانات والحساب الأول والبناء والتحقق من الاتصال، و[قالب متغيرات البيئة](.env.example) لأسماء المتغيرات. يُضبط مفتاح `GEMINI_API_KEY` على الخادم، ولا يوضع في ملفات المستودع.
