# حقيبة المهام

تطبيق ويب عربي لتنظيم المهام والوثائق والتراخيص والتجديدات والمواعيد. يعمل بحسابات وصلاحيات، ويحفظ السجلات المشتركة في MySQL لتظهر عند فتح التطبيق من أجهزة مختلفة.

**[افتح حقيبة المهام على الموقع الرسمي](https://haqibat-almaham.carpetbazar.org/)**

## المساعد الذكي

يستخدم المساعد Gemini لفهم الطلب بالعربية، ثم يبحث خادم التطبيق في السجلات التي تسمح بها صلاحيات المستخدم. يمكنه تجهيز سجل جديد أو تقرير أو مشاركة، ويطلب المعلومات الناقصة في المحادثة. تتم مراجعة السجل قبل حفظه، وتُراجع المشاركة قبل الإرسال. يدعم المساعد الإملاء وقراءة الرد بالعربية بحسب إمكانات المتصفح والجهاز.

### استيراد الوثائق من مرفق مؤقت

من محادثة المساعد، اختر «إرفاق ملف مؤقت» وأرسل طلبًا مثل «استخرج رخص سير المركبات والتأمين، وجهّز تذكيرًا قبل الانتهاء بـ30 يومًا». يدعم الاستيراد ملفات Excel بصيغة XLSX وWord بصيغة DOCX وPDF حتى 3 ميغابايت للملف و100 سجل للدفعة، ويتطلب صلاحية كتابة السجلات.

تتيح المعاينة تصحيح التاريخ وتعيين التصنيف والمختص، ثم اعتماد إنشاء السجلات أو تحديث المطابق منها. ينشئ الخادم الوثائق والتذكيرات المعتمدة في عملية حفظ واحدة. يعالج التطبيق المرفق في الذاكرة. يُرسل PDF أو النص المستخرج من Excel وWord إلى Gemini، ويزول المرفق من المحادثة عند الإغلاق أو الإزالة أو بعد 15 دقيقة. تحفظ قاعدة البيانات السجلات المعتمدة فقط.

## واجهة الدخول

تضم واجهة الدخول بطاقة زجاجية بإطار نيون وزر الانطلاق الهيدروليكي. يفتح المصباح نموذج الدخول، وتبقى خيارات لون الإضاءة مستقلة عن حالة تسجيل الدخول.

## التشغيل المحلي

يتطلب المشروع Node.js 22.12 أو أحدث.

```sh
npm ci
npm run dev
```

يعمل التشغيل الافتراضي في وضع المعاينة المحلية. لإعداد النسخة المشتركة على هوستينجر، راجع [دليل إعداد الخادم وMySQL](database/HOSTINGER.md). يحتوي [ملف متغيرات البيئة](.env.example) على أسماء المفاتيح اللازمة للإعداد.
