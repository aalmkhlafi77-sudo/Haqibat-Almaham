# تشغيل حقيبة المهام على هوستينجر

## إعداد نسخة اختبار مشتركة

1. أنشئ قاعدة MySQL مستقلة بترميز `utf8mb4` واربط بها مستخدم التطبيق. نفّذ `004_shared_workspace.sql` بحساب يملك صلاحية إنشاء الجداول. يحتاج مستخدم التشغيل إلى صلاحيات `SELECT` و`INSERT` و`UPDATE` على جداول التطبيق، و`DELETE` على جدول `haqibat_accounts` لحذف حسابات المستخدمين.
2. اضبط `DB_HOST` و`DB_PORT` و`DB_NAME` و`DB_USER` و`DB_PASSWORD` و`SESSION_SECRET` في متغيرات الخادم. استخدم سر جلسات عشوائيًا بطول 32 حرفًا على الأقل واحتفظ بقيمته عبر عمليات إعادة التشغيل.
3. اضبط `OWNER_USERNAME` و`OWNER_PASSWORD` عند التشغيل الأول. الحد الأدنى لكلمة المرور 12 حرفًا. يمكن ضبط `OWNER_DISPLAY_NAME` و`OWNER_EMAIL`. بعد التحقق من الدخول، أزل كلمة مرور التهيئة من متغيرات الاستضافة.
4. استخدم بيئة Node.js 22.12 أو أحدث، وشغّل خطوات الإنتاج التالية عبر إعدادات التطبيق أو سطر الأوامر. يستخدم الخادم المنفذ الذي تضبطه الاستضافة عبر `PORT`.

   ```sh
   npm ci
   npm run lint
   npm run build:shared
   NODE_ENV=production npm start
   ```

في إعدادات hPanel اختر `Other` و`npm`. عيّن أمر البناء إلى `npm run build:shared` ومجلد المخرجات إلى `dist` وملف التشغيل إلى `server.js`. اضبط `NODE_ENV=production` في متغيرات البيئة.

5. فعّل HTTPS على الدومين الفرعي. تحقّق من أن `/api/health` يرجع `databaseReady: true` و`storageStage: "mysql"`. افتح التطبيق في جلستين منفصلتين. أنشئ سجلًا في الأولى وافتحه وعدّله في الثانية، ثم أعد تشغيل الخادم وأكّد بقاء التعديل. اختبر تصدير النسخة واستعادتها على قاعدة منفصلة.

## التخزين ودورة النسخ الاحتياطي

تُحفظ مساحة عمل واحدة في `haqibat_workspace`. متطلبات الإصدار الحالي تُدار عبر لقطة JSON من نموذج التطبيق القائم، مع معاملة وقفل صف ورقم مراجعة لحماية الكتابة. تحفظ `haqibat_accounts` الحسابات بمعزل عن بيانات العمل. الجداول العلائقية المقترحة في `001_init_haqibat_almaham.sql` مرجع للتوسع، واستيرادها اختياري لهذا التشغيل. ملف `002_seed_demo_data.sql` خاص بالبيانات التجريبية. يبدأ الإصدار المشترك بسجلات تشغيلية فارغة وأنواع المهام الأساسية فقط.

تظل إعدادات المظهر والتنقل والفلاتر مرتبطة بالمتصفح. تُحفظ إعدادات التنبيهات وقواعد 3A والتكاملات في مساحة العمل المشتركة. يحتاج المستخدم إلى تحديث السجلات أو فتح الصفحة من جديد لرؤية آخر تغييرات الأجهزة الأخرى. يرفض الخادم حفظ تغييرات مبنية على مراجعة قديمة ويطلب تحديث السجلات.

تستعيد نسخة JSON التشغيلية السجلات وإعداداتها وتحتفظ قاعدة البيانات تلقائيًا بالحالة السابقة في `haqibat_restore_points`. ملفات النسخ من الواجهة تستثني حسابات الدخول والمرفقات الثنائية. لاستعادة الخدمة والحسابات عند فقد قاعدة البيانات، تُستخدم نسخة قاعدة البيانات التي تشمل جداول التشغيل والحسابات.

لتشغيل المعاينة المحلية، استخدم `npm run dev` من دون `APP_STORAGE=mysql`. لتشغيل نسخة اختبار متصلة بقاعدة منفصلة أثناء التطوير، استخدم `APP_STORAGE=mysql` مع إعدادات القاعدة وحساب المالك. يبقى وضع المعاينة التجريبي مستقلاً عن سجلات النشر المشترك.
